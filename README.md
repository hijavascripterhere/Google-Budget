# Google Budget

A Google-themed budgeting website designed to provide a simple, clean, and familiar interface for managing personal finances.

# Overview

Google Budget is a front-end budgeting project inspired by Google's clean and minimal design language. The project focuses on making budgeting easy to understand while keeping the interface lightweight and visually simple.

# Features

💰 Budget and expense tracking

📊 Simple financial overview

🎨 Google-inspired visual design

🧩 Reusable CSS variables for colors and styling

📱 Responsive layout

🖥️ Clean, minimal interface

🖼️ Custom icons and visual assets

# Tech Stack

HTML5 — page structure

CSS3 — styling, layout, animations, and theming

JavaScript — interactive functionality

Git — version control
